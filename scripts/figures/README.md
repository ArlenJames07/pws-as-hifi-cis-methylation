# Manuscript figure scripts

The canonical figure programs are `FIGURE_1.py` through `FIGURE_5.py`.
The proposed Q1 resubmission layout and evidence gates are in
`docs/figure_redesign_q1.md`. A separate Figure 5 renderer based on the newly
added duplicon and repeat-methylation summaries is
`FIGURE_5_DUPLICON_REPEAT.py`; it leaves the historical `FIGURE_5.py` intact.
After running analysis/01 and duplicons/05–08, invoke it without arguments:

```bash
python3 scripts/figures/FIGURE_5_DUPLICON_REPEAT.py
```

It requires the real local `breakpoint_status.tsv`, `methylation_regions.tsv`,
and common reciprocal CN=1 table, and writes PNG, PDF, SVG plus an audit note
to `results/07_figures/figure_5/`.

When run directly without `--outdir`, each script writes beneath the repository
results directory:

```text
results/07_figures/
├── figure_1/{figures,tables,logs,reports}/
├── figure_2/{figures,tables,reports}/
├── figure_3/{figures,tables,logs,reports}/
├── figure_4/{figures,tables,reports}/
└── figure_5/{figures,tables,reports}/
```

For example:

```bash
python3 scripts/figures/FIGURE_1.py
```

creates `results/07_figures/figure_1/figures/Figure1.png` and the associated
tables. An explicit `--outdir` still overrides the default.

After editing Figure 1 layout or styling, redraw it from its existing plotting
tables without rereading the large BAM and methylation files:

```bash
python3 scripts/figures/FIGURE_1.py --render-only
```

The shared 17-sample cohort includes six DiGeorge samples: `008D`, `009D`,
`010D`, `011D`, `012D`, and `015D`. They are recognized as the `DIGEORGE`
analysis group (displayed as `DiGeorge`) in cohort-wide summaries. Analyses
that specifically estimate PWS/AS chr15 deletion breakpoints retain their
biologically defined PWS/AS-only comparison; DiGeorge samples remain included
in genome-wide, QC, phasing, CNV, SV, and methylation summaries and are not
misclassified as a chr15 deletion group.

The current `FIGURE_2.py` is a standalone renderer of the cohort-wide tables
from `scripts/analysis/01–03`. The older Nextflow `MAKE_FIGURE_2` process still
passes command-line options from a previous Figure 2 implementation and has
not been updated to stage the new cohort-wide analysis outputs. For this
resubmission, run the pre-figure Nextflow stages with `run_figures: false`,
followed by `scripts/analysis/run_analysis.py` and the standalone figure
scripts; do not treat `--run_figures true` as a validated figure-generation
path.

Figures 4 and 5 are render-only: their required precomputed input tables are
not generated by another script in this repository. Run them through Nextflow
only after supplying `figure4_tables` or `figure5_tables` in the parameter
file. Required table names are defined in each script's
`REQUIRED_INPUT_TABLES` constant.

Primary outputs:

| Script | Main output |
|---|---|
| `FIGURE_1.py` | `Figure1.{png,pdf,svg}` plus QC and assignment tables |
| `FIGURE_2.py` | `Figure2.{png,pdf,svg}` and supplementary profile/depth figures |
| `FIGURE_3.py` | `Figure3_boundary_mapping_improved.*` |
| `FIGURE_4.py` | `Figure4_per_molecule_cis_architecture.*` |
| `FIGURE_5.py` | `Figure5_v7.{png,pdf}` |

See the repository-level README for required parameters, workflow execution,
output locations, and data-privacy rules.

## Reciprocal cis architecture

The current `FIGURE_2.py` reads the participant and window tables produced by
`scripts/analysis/run_analysis.py` and makes three panels: signed direct
parent-associated Δβ, prespecified regional contrasts, and phase-invariant ASM
in Control and DiGeorge participants. The retained-copy heatmap, detailed
profiles, and depth sensitivity are supplementary. It does not rerun DSS or
the upstream methylation analysis. Figure 1 retains the deletion-span and
diagnostic-classification displays.

```bash
python3 scripts/analysis/run_analysis.py
python3 scripts/figures/FIGURE_2.py
```
